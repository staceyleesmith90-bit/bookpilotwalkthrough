# Study: a competing "Claude edits my reels" product (public 16-min sales demo)

Watched for inspiration only. Nothing of theirs (code, templates, animations, wording) is used.

## Their workflow
1. Drop footage in, say "new reel" → transcript → rough cut (best takes, ~4-5 min for a 1:48 clip).
2. **Line-by-line review widget**: every kept line with its length in seconds; per line a
   paperclip (give a reference: link, timestamp or file), a note, and a delete button;
   "Send my edits" turns it all into one tidy message. Re-cut is faster each pass.
3. **Style plan**: a table beat → line → treatment (hook card, plain footage, custom animation
   window, karaoke captions, full-screen takeover), plus the sound plan ("mouse click, pop,
   woosh … nothing repeats back to back"). User approves or changes by voice before the build.
4. **Named effects library**: effects have names ("full-screen takeover"); the user can teach a
   new one and save it by name.
5. **Custom animation windows**: code-built motion graphics that SHOW what is being said
   (e.g. an app window exporting, a chat box typing) — also used for brand-deal product demos.
6. Build ~16 min. Output: a postable MP4 **or a CapCut project** with every piece editable:
   graphics and sound effects as separate clips in the media bin, text as real CapCut text.
   The user adds ~10% personal touch in CapCut (e.g. CapCut's auto captions in their font).
7. Final "be my sound designer" pass + AI-generated music bed.

## Why it looks better
- **Restraint**: most of the reel is plain footage with small single-word captions; one
  special treatment per beat, never several at once.
- Illustrative UI/product animations instead of stickers.
- The user approves the plan before the build, so the result matches taste.

## Their limits (our advantages)
- Mac-first; Windows "more hands-on". About 40 minutes of setup. One-off price, no monthly updates.

## To build (our own versions)
- CapCut project export (editable text, graphics + sounds as separate clips).
- Line-by-line rough-cut review on our review page.
- Style-plan approval step; named effects the user can save.
- Animation windows rendered from HTML (UI mockups, product demos, charts, checklists).
- "Clean" restraint look: plain footage by default, one treatment per beat.
