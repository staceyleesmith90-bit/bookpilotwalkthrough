# Market research: what reel-editing products promise (and how Reel Studio answers)

Notes from a competitor's launch live (a Claude Code "reels editing engine", $97 / $67 launch,
7-day window, ~45 min setup, CapCut-based). Ideas only — no content copied.

| What buyers are promised there | Reel Studio |
|---|---|
| Brand style from a Canva design / website / preset packs | ✅ website, logo/mood board, **Canva/Figma style guide** (brand-onboarding route E), 7 presets |
| Works in other languages (Spanish captions, hooks) | ✅ transcription + captions in the spoken language; hooks written in it. UI is English (roadmap: Spanish UI) |
| Mac + PC | ✅ installers for both |
| Chop long clips into many 6 s b-roll clips, hooks on each, captions map, overnight batch | ✅ `chop` (quality-scored, no scene cuts) + `trial` (hook reels + captions.md) |
| Interview that learns preferences, niche, voice | ✅ brand interview + **voice hub** (learns from last 15 reels) |
| "Tutor me": why a viral post worked | ✅ `tutor-me` skill (principles, never copying) |
| Voiceover reels that order clips by story | ✅ `broll-batch` step 4 + voiceover format |
| Commands like "set me up" / "update me", update pings | ✅ `help-me` skill, `python -m engine update`, update notice in setup-check |
| Hook library + psychology + script writer (paid add-on) | ✅ included: `hooks-and-scripts` (original formulas) |
| "How do I…" answers inside the tool | ✅ `help-me` |
| Outputs: raw (CapCut project) / well-done (final) / medium (timeline + overlay layers) | ✅ final video (no CapCut needed) + **layers export** (video · transparent graphics · captions · audio) for any editor |
| Needs a strong computer, ~45 min setup, $20 Claude plan | same class: heavy work local; Claude only plans (see usage-and-credits) |
| Custom animated explainers (e.g. app-connection animations) | roadmap: motion-graphics cards |
| Notion content pipeline, carousels | roadmap / separate products |

Where Reel Studio goes further: finished video without CapCut, premium glass/callout graphics,
auto director (stabilise, face-framed zooms), measured noise clean-up, colour correction,
automatic quality check, trending-sound suggestions, template library, built-in free music,
drag-and-drop editor.

Positioning lesson from the live: be honest about who it's for (people who want to direct,
not edit), set expectations (setup time, computer power, it still takes minutes to render), and
price below one hired edit.
