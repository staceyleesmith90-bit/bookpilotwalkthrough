# Script check

Shared rules: `script-studio/SKILL.md`.

Read the script (their paste or `my-scripts/…`). Give each check 🟢 / 🟡 / 🔴 with a few words:
1. **Hook** — would a stranger stop in 2 s? (a shape from hook-shapes.md, a real detail)
2. **First picture** — does the opening shot work with the sound off?
3. **One idea** — can you say the reel in one sentence?
4. **Specific** — real numbers, names, objects, times; no vague filler
5. **Show-me moment** — at least one thing the camera *sees* that proves it
6. **Pace** — a new beat every 2–3 s, nothing said twice, fits the length (2.5 words/s)
7. **Payoff** — the last 3 s keep the hook's promise
8. **Ask** — one, and it matches the job (reach / trust / sell)
Then: **what's already strong** (one line) · **the one fix that matters most** · the rewritten line(s).
No overall score. Offer: *Apply it · Show me another fix · Trim to __ s*. Applying keeps their words wherever
possible and saves the new version in the same file (previous version under "Earlier draft").
