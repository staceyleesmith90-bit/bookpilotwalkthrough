# Content week

Shared rules: `script-studio/SKILL.md`.

1. Ask one thing: "What's this week about?" — *More followers · More trust · Sell something · Just keep posting*.
   (Skip if obvious.) Then the mix: followers → 3 reach, 1 trust, 1 sell; trust → 1/3/1; sell → 1/2/2;
   keep posting → 2/2/1 (no sell if they have no offer).
2. Five reels from their story bank (moments, things, topics, proof) and `my-scripts/ideas.md`; never five
   of the same shape. For each: job · working title · best hook (shape) · reel shape · show-me moment ·
   faceless or talking.
3. **Batch plan:** group by place/outfit/light ("garden, morning: #1 #4 · desk: #2 #3 #5"), the b-roll to grab
   while there, and a posting order (strongest reach reel first).
4. Write `my-scripts/week.md` and start a file per reel (title + hook + shape). Offer to script the first one
   now (→ `write-my-script`), or hooks for any of them (→ `hook-lab`).
