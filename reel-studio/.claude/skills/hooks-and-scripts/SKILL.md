# Hooks & scripts (in the user's voice)

Always read `brand/voice.md` first (if missing, suggest `learn-me` or ask 3 quick questions:
who they help, 3 words for their tone, a phrase they always say).

## Hook formulas (original set — mix, don't template-spam)
| Formula | Shape | Why it works |
|---|---|---|
| Curiosity gap | "The ___ nobody tells you about ___" | brain wants the missing piece |
| Bold claim | "This $12 thing replaced my ___" | surprise + specificity |
| Relatable pain | "If you ___ every morning, watch this" | viewer feels seen |
| POV | "POV: you finally ___" | instant role-play, emotion |
| Mistake | "Stop ___ (do this instead)" | loss aversion |
| Countdown | "3 things I'd never ___ again" | open loop until #3 |
| Before/after | "Day 1 vs day 30 of ___" | visual contrast, payoff |
| Contrarian | "Unpopular opinion: ___" | debate, comments |
| Proof first | "This got me ___ in ___ days — here's how" | credibility then value |
| Behind the scenes | "What ___ actually looks like" | authenticity |

Rules: first 3 words carry the hook · specific numbers beat vague words · promise must be
paid off · one idea per reel · say it in ≤ 2 seconds · on-screen hook ≤ 8 words.

## Script shape (20–45 s)
Hook (0–3 s) → context in one line → 3 beats (each = one caption line + one visual change) →
payoff → CTA that matches the goal (save / comment a word / follow / link in bio).

Give 3 hook options + 1 script; mark the words to highlight in captions (they become the
brand-coloured keywords). For captions (post text): first line = hook restated, 2–4 short
lines of value, CTA, 3–5 niche hashtags. Never invent facts, results or testimonials.
