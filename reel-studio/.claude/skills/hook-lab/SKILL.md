# Hook lab

Shared rules: `script-studio/SKILL.md`. Shapes: `script-studio/hook-shapes.md`.

1. Get the idea in one line (from their message, `my-scripts/ideas.md` or a story-bank moment). Label its job
   (reach / trust / sell). Faceless or music-only reel? Then hooks = first picture + cover line only.
2. Write **8 hooks from 8 different shapes**, each as:
   `#n · shape — "spoken first line" · first picture: … · cover: "≤7 words"`
   Use their real moments and words; one oddly specific detail each.
3. Mark **two to test** (far-apart shapes) with one line each on why.
4. Ask: *Use #a · Use #b · Mix two · More like #n*. Save the winner(s) at the top of the reel's file
   `my-scripts/<date>-<slug>.md` (create it) and offer `write-my-script`.
