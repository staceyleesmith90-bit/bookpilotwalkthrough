# Reel shapes (beat by beat)

Times are for a 20–40 s reel. Every shape has one **show-me moment** (★) the studio can make big on screen.

| Shape | Job | Beats |
|---|---|---|
| **Little story** | trust | hook (0–2 s) → where we were (1 line) → what happened ★ → how it felt → small lesson or punchline → ask |
| **Expectation vs real** | reach | the plan (text on screen) → the plan falling apart ★ → the honest truth → funny tag |
| **Three things** | reach / trust | promise "3 ___" → 1 (fast) → 2 (fast) → 3, the best one ★ → ask (save it) |
| **Wrong way / right way** | trust | wrong way on screen → why it fails (1 line) → right way ★ → the result |
| **Proof first** | sell | the result ★ → "here's what changed" → 2–3 steps → who it's for → ask (comment a word / link) |
| **Day in the life** | trust | time stamp + first moment → 4–6 quick moments with one-line labels → the moment it was all for ★ |
| **Answer a question** | trust / sell | the question on screen (comment style) → the short answer → the reason ★ → offer more |
| **Before → after** | reach / sell | before (hold 1 s) → the work, sped up → after ★ → one line on how |

## Pace
- A new picture every 1.5–3 s; a new idea every beat. If two beats say the same thing, cut one.
- Spoken script: 2.5 words a second is natural. 30 s ≈ 75 words. Write it, then count.
- The ask matches the job: reach → "follow for part 2" / "send this to ___"; trust → "save this";
  sell → "comment ___ and I'll send it" / "link in bio".
