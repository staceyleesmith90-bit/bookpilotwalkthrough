# Voice hub

1. Ask for their profile link (TikTok/YouTube profiles list automatically; for Instagram ask for
   5–15 reel links). Run `python -m engine learn-me <url> [--options 15]`.
2. Read `brand/voice/reels.json` ONCE and write `brand/voice.md` (≤ 60 lines):
   who they talk to · topics · tone (3 words) · how they open (their real hook patterns, quoted)
   · phrases they repeat · words/emoji they use · words they never use · how they end/CTA ·
   caption style (length, emoji, hashtags) · language(s).
3. Show them a 5-line summary: "Here's how you sound — anything wrong?" and fix it.
4. From now on read brand/voice.md before writing any hook, caption or script.
