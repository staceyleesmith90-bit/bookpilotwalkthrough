# Find the demo

First read `.claude/skills/script-kit-library/house-rules.md` and follow it the whole way through.

A claim you tell gets doubted. A claim you show is proof. This skill finds what the viewer can see.

## 1. Find the reel

An idea they typed, a script file they named, or the most recently changed file in `script-desk/scripts/`. Name
which one in your first line.

## 2. Read

`.claude/skills/script-kit-library/method.md` (principle 4 and the registers),
`.claude/skills/script-kit-library/edit-words.md`, the lever-to-edit map in
`.claude/skills/script-kit-library/levers.md`, and `script-desk/about-me.md` if it exists.

## 3. Name the claim

One line: "Your claim: ...". This is the thing the reel needs the viewer to believe.

## 4. Give three to five demos

Draw from these kinds: a before and after, a live demo, a number counting up, a prop, their screen, a drawing (a
whiteboard or a notebook), or the result itself. For each one:

- **What they see:** one line.
- **Where it lands:** quote the line or name the beat it lands on.
- **Edit note:** in the engine's words, like `(edit: breakaway card, before and after)`.
- **Why it works:** one line.

Keep every demo to something they can film where the reel is set, with what they already have. Flag anything
that needs a prop they'd have to go get.

On a confessional reel, suggest at most one quiet visual (a held prop, one word on screen) and no breakaway
cards. The words carry a confessional.

## 5. Pick one

Recommend one demo and say why in one line.

## 6. Save

- If the reel has a script file: fill `## The demo` with the recommended demo (mark it "suggested" until they
  choose) and put its edit note on the matching line under "Script". Move the old demo's note, never add a
  second one. If "Filming direction" describes the old shot, update that line. If the file has check notes, add one
  line under them: "The demo changed after this check. Say `check my script` to check it again."
- If it was only an idea: start a script file for it with the idea and the demo filled in, and add the idea to
  `script-desk/ideas.md` if it isn't there yet.

## 7. Next

One line: "Next: `script this` to write the reel around the demo." If the reel is already scripted: "Next:
`check my script`."
