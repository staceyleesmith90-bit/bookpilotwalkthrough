Overview

Executive Summary

BookPilot manages appointments as the practice's booking source of truth. The BookPilot Companion runs locally on an authorised Windows practice workstation, where it reads visible diary elements through Windows UI Automation and sends a minimal observation to BookPilot. BookPilot then compares the observation against its own appointments, and reception confirms or reviews the result. The entire process is read-only.

Billing and clinical information are never accessed. The Companion does not click, type, modify or delete anything in the legacy calendar, and it never inspects the application's database, files, DLLs or network traffic.

16 Step 16 — Device revocation

Device Revocation

When a device is revoked in BookPilot, subsequent uploads are rejected with 401 Unauthorized, queued observations are retained, and the Companion shows a re-pairing requirement. This protects practices if a workstation is lost or unauthorised.

Security & privacy boundaries

Security and Privacy Boundaries

✓ The Companion Does

  • Observe selected visible diary elements
  • Use Windows UI Automation (no coordinates or pixels)
  • Submit minimal appointment observations
  • Support offline queueing (DPAPI-encrypted)
  • Support device revocation and re-pairing
  • Preserve audit history
  • Allow pause and unpair at any time

✕ The Companion Does Not

  • Access the MEDEDI database
  • Inspect proprietary files or DLLs
  • Intercept network traffic
  • Capture billing or claims
  • Capture diagnoses or clinical notes
  • Write into the diary
  • Click buttons or type information
  • Delete BookPilot appointments
  • Claim official CGM integration
Data classificationAll data in this walkthrough is fictional demonstration data. No real MEDEDI installation was accessed, and no database, DLL, internal file or network traffic was inspected.

Known limitations
  • Raw Win32 window moves on the WPF simulator can leave the UIA provider serving stale/empty Name/HelpText properties (0 parsed entries until the target restarts) — a simulator/provider limitation, not a Companion defect.

  • Local HTTP was used for development; production must enforce TLS.
